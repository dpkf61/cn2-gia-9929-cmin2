## 三网优化到底优化了什么

CN2 GIA、AS9929、CMIN2这三个缩写背后是三大运营商各自的国际精品网络。

普通国际线路走的是公网骨干，高峰期拥堵、绕路、丢包都很常见。三网优化线路相当于给你开了条专用通道：电信用户的数据包走中国电信国际CTGNet（就是原来的CN2 GIA），联通用户走China Unicom Premium（AS9929），移动用户走China Mobile International N2（CMIN2）。

实际效果差多少？韩国KT机房用CN2 GIA线路，延迟能稳定在30-60ms；普通线路可能要跑到100ms以上，晚高峰还会飙到200ms甚至直接丢包。香港BGP节点用优化线路，平均延迟40ms；普通线路可能70-80ms起步。

## 三网优化适合谁，不适合谁

**适合：**
- 建站，尤其是面向国内访客的博客、企业站、API服务
- 需要稳定低延迟的应用（游戏服务器、实时通信、视频推流）

**不适合：**
- 纯海外受众，国内访问需求为零——普通国际线路够用，没必要为三网优化多花钱
